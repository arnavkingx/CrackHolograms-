# CrackHolograms
🌐 Modrinth
https://modrinth.com/plugin/crackholograms

**CrackHolograms** is a lightweight and easy-to-use hologram plugin for Minecraft Paper servers.

Create clean, customizable holograms with multiple lines and simple configuration.

## ✨ Features

- Create custom holograms
- Multiple lines support
- Persistent holograms
- Easy configuration
- In-game and console support
- Lightweight TextDisplay-based holograms
- Simple server management
- Configurable hologram settings

## 📦 Installation

1. Download `CrackHolograms-1.0.0.jar`
2. Put the JAR file into your server's `plugins` folder.
3. Start or restart your Paper server.
4. Configure the generated files inside the `plugins/CrackHolograms` folder.

## 🖥️ Compatibility

- **Platform:** Paper
- **Minecraft:** 1.21.11
- **Java:** 21+
- **Version:** 1.0.0

> CrackHolograms 1.0.0 is built against the Paper 1.21.11 API. Other Minecraft versions may work, but they are not guaranteed unless tested.

## ⚙️ Configuration

After the first server startup, CrackHolograms creates its configuration files automatically.

Edit the configuration files inside:

`plugins/CrackHolograms/`

## 🔧 Building From Source

- Java 21+
